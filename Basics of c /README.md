# C Programming Practice

A collection of C programming modules that I practice daily to build strong
fundamentals and problem-solving skills, as part of my preparation for a
career in hardware engineering.

## About
Each module focuses on a specific concept in C. I add new programs regularly
and revisit older ones to improve them.

## Topics Covered
- Basics: variables, data types, operators, input/output
- Control flow: conditionals and loops
- Functions and recursion
- Arrays and strings
- Pointers and memory management
- Structures and file handling

## Structure
Each folder contains programs for one module, with each file focusing on one
concept or problem.

## How to Run
gcc filename.c -o output
./output

## Goal
Practice consistently, one program at a time, and get better every day.
